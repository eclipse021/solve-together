## 짧은 회고

### 준현

- 접근: 이분 탐색으로 최소가 되는 레벨을 탐색했음 -> N=30만 으로 이중 for 문 사용 x
- 막힌 지점: 문제 조건을 정확히 읽지 않아 시간 계산을 잘못 구현했고, 이분 탐색 범위를 (mid + 1, end)로 할지 (mid, end)로 할지 헷갈렸다.
- 다음에 기억할 것:
  - 종료 조건이 start > end 이니, (mid, end)는 start == end일 때 범위가 줄지 않아 무한 재귀가 될 수 있으므로 mid + 1로 해야한다.
  - 헷갈릴 때는 1~5, 1~6 범위를 직접 해보면 이해하기 쉽다!

### 준희

- 접근: 보자마자 이진탐색으로 최소 숙련도를 찾자고 판단. 시간 계산식(`diff > level`이면 `(time_cur + time_prev) * (diff - level) + time_cur`)만 세우면 바로 풀리는 문제라 금방 구현함.
- 막힌 지점: 14번 테케가 계속 틀려서 하한 경계 처리로 막음. 처음엔 급하게 예외를 하나 넣어 통과시켰음.
- 다음에 기억할 것: 이진탐색 하한 경계(정답이 1이거나 탐색이 최솟값까지 내려가는 경우)는 특정 테케 땜빵 대신 `mid == 1`을 feasible일 때만 반환하도록 처리해야 안전함.
