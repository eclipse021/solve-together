## 짧은 회고

### 준현

- 접근: 1. 로봇 구조체를 만들어 2. 현재 위치와 목표 위치 리스트를 관리하고, 3. 매 시간 문제의 이동 우선순위에 따라 한 칸씩 이동시킨 뒤 4. unordered_map으로 같은 좌표의 로봇 수를 집계해 충돌 횟수를 계산했다.
- 막힌 지점: 처음 구현은 40분 정도내로 했지만 디버깅에서 50분이상 소요됨 (규칙 해석 + 디버깅 문제인듯)
  - 이동 규칙을 처음에 잘못 해석해 로직을 이상하게 세워 로봇이 목적지에 도달하지 못하는 경우가 발생
  - 이를 디버깅하는 과정에서 answer 초기화 위치까지 잘못 변경해 추가 오답이 발생했다.
- 다음에 기억할 것:
  - 문제 규칙 해석 부분에서 계속되는 실수가 보임 -> 특히 이동 부분 로직 짤 때 해석에 주의해야할듯
  - m.first vs m.second

### 준희

- 접근: 로봇마다 경로를 시뮬레이션하며 매 시각 위치를 `paths[time]`에 기록하고, 시각별로 `Counter`에서 2대 이상 겹친 칸 수를 합산.
- 막힌 지점 (2곳에서 멈칫):
  1) `temp = start`로 두니 얕은 복사(참조 공유)라 모든 기록이 마지막 좌표로 덮어써짐 → `start[:]`로 해결.
  2) 세그먼트 도착점을 while 안에서 기록하면 경유점이 두 번 찍힘(도착=다음 세그먼트 출발) → 도착점은 while에서 빼고 마지막에 한 번만 기록. `time`은 세그먼트 사이에 리셋하지 않아 시각축이 이어짐.
- 다음에 기억할 것: 리스트 복사는 `[:]`로 참조 공유 방지. 경로를 이어 붙일 때 경유점 중복 기록 주의 — 한쪽에서만 기록하면 됨.
