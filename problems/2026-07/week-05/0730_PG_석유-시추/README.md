## 짧은 회고

### 준현

- 접근: 처음에는 각 열마다 BFS를 실행해 연결된 석유 덩어리의 크기를 구했지만, 같은 덩어리를 반복해서 탐색해 효율성 테스트를 통과하지 못했다. 이후 전체 격자를 한 번만 BFS로 탐색해 각 석유 덩어리에 번호를 부여하고 크기를 저장한 뒤, 열마다 걸쳐 있는 덩어리의 크기를 합산하는 방식으로 변경했다.
- 막힌 지점: 500 * 500 = 25000으로 계산해서 시간 복잡도 계산을 잘못 구해 풀이 방식을 잘못 설정함
- 다음에 기억할 것: 
  - map 순회 방식 -> for (auto& m : um) 
  - m.first : key, m.second : value 
  - if(um.find(key) == um.end()) -> 값 있는지 검사

### 준희

- 접근: 격자 BFS로 유전 덩어리(연결 컴포넌트)를 찾고, 각 덩어리의 크기를 그 덩어리가 걸친 열마다 `spaces[열] += 크기`로 누적. 마지막에 `max(spaces)` 반환.
- 막힌 지점: 딱히 없이 무난하게 금방 풀림.
- 다음에 기억할 것: "각 열에 시추" = 그 열을 지나는 덩어리 크기 합. 덩어리별로 (크기, 걸친 열 집합) 구해 열에 더하면 매 열마다 다시 세지 않아 O(N·M).
