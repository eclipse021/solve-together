## 짧은 회고

### 준현

- 접근: 연산자들을 하나씩 나열해 모든 순열을 만들었지만, 같은 연산자까지 서로 다른 원소로 취급해 시간 초과가 뜸
- 막힌 지점: 일반 순열 방식은 최대 11!에 가까운 탐색이 발생해 시간초과가 났고, 같은 값이 여러 개 있는 순열에서는 중복을 제거하는 방식이 필요했다.
- 다음에 기억할 것: 같은 원소가 반복되는 순열은 원소별 남은 개수를 배열에 저장하고, DFS에서 개수를 하나씩 줄였다가 복구하는 방식으로 구현하자!!

### 준희

- 접근: DFS 백트래킹. 연산자 4종(`+ - * /`)의 남은 개수를 배열로 두고, 하나 쓰면 `-=1` 하고 재귀, 돌아오면 `+=1`로 복구. 깊이가 `N-1`에 도달하면 결과값으로 max/min 갱신.
- 막힌 지점: 딱히 크게 막힌 곳 없이 풀림. 나눗셈은 `int(total / n)`으로 0 방향 버림 처리.
- 다음에 기억할 것: 연산자처럼 같은 원소가 여러 개인 순열은 개수 배열 + 소모/복구 DFS로 중복 없이 완전탐색하면 됨. 오랜만에 DFS 복습해서 손에 익히기 좋았음.
