### 준희

- 접근: "모든 컬럼 조합 완전탐색 + set으로 유일성/최소성 판정"이라는 뼈대와 흐름은 스스로 다 잡음. 컬럼 조합을 크기 오름차순으로 만들어 유일성(각 조합으로 만든 튜플 집합 크기 == 행 개수) 검사 후, 기존 후보키의 부분집합이면 제외하는 방식으로 최소성 처리.
- 막힌 지점: 처음에 컬럼 인덱스가 아니라 실제 값 리스트를 set에 담으려다 막힘 → 인덱스로 다뤄야 한다는 것. 그리고 부분집합 판정 `issubset`, 조합을 리스트에 펼쳐 담는 `extend`의 존재를 잊고 있어서 그 세 가지를 힌트로 받음. 전체 로직이 아니라 디테일 도움.
- 다음에 기억할 것: 값 자체 대신 인덱스로 조합/집합을 다루기(값은 unhashable·중복 이슈, 인덱스는 깔끔). `set.issubset()`으로 부분집합 판정 → 최소성 검사에 유용. `list.extend()`는 iterable 내용물만 펼쳐 담음(vs `append`). 후보키 = 유일성 + 최소성, 둘 다 만족해야 함.
