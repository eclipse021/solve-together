## 짧은 회고

### 준현

- 접근: dp로 해결
- 막힌 지점: x
- 다음에 기억할 것: x

### 준희

- 접근: DP 문제 같긴 했지만 DP가 약해서 다른 방법을 찾다가 BFS로 풀었음. `(x, 0)`을 큐에 넣고 `+n`, `×2`, `×3` 세 연산으로 넓혀가며, y를 넘는 수는 버림. y에 처음 도달한 순간의 횟수가 최소이므로 바로 반환하고, 끝까지 못 가면 -1.
- 막힌 지점: 2차원 배열 BFS에서 visited를 쓰는 건 알았는데, 이런 1차원(숫자) 상태에도 visited가 필요한지 몰랐음. 없으면 같은 숫자가 여러 경로로 큐에 중복해서 쌓임 → `set`으로 방문한 숫자를 기록.
- 다음에 기억할 것: BFS는 격자든 숫자든 상태 종류와 상관없이, 같은 상태를 다시 넣지 않도록 visited가 필요하다.
