## 짧은 회고

### 준현

- 접근: 처음에는 어떤 조건으로 정렬할지 고민했는데, 그냥 두 수를 합치고 커지는 방향으로 문제 해석 그대로 정렬 진행함
- 막힌 지점: 자바 sort 문법이 헷갈림
- 다음에 기억할 것:
  - list.sort((a,b) -> {return Integer.compare(a,b);});

### 준희

- 접근: 이전(5/24)에 풀어둔 풀이를 올림. 숫자를 모두 문자열로 바꾸고, 원소가 1000 이하라 `x*3`(3번 반복한 문자열)을 키로 내림차순 정렬한 뒤 이어 붙임. 전부 0이면 `'0'` 반환.
- 막힌 지점: 당시 풀이 시간·힌트 여부 기록 없음.
- 다음에 기억할 것: 이어 붙였을 때 커지는 순서 정렬은 문자열 반복(`x*3`)을 키로 비교. 결과가 `'000'`처럼 되는 경우는 `'0'`으로 처리.
