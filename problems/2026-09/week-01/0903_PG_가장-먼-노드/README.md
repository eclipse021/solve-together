## 짧은 회고

### 준현

- 접근: bfs로 1번부터 각 노드의 거리를 dist로 저장 후 한번에 가장 먼 노드 수 계산
- 막힌 지점: x
- 다음에 기억할 것: x

### 준희

- 접근: 인접 리스트로 양방향 그래프를 만들고, 1번 노드부터 BFS. `distance`를 -1로 초기화해 방문 체크와 거리 누적을 한 배열로 처리(`distance[nd] = distance[now] + 1`). 마지막에 `max(distance)`의 개수를 `count`로 반환.
- 막힌 지점: 로직은 무난했고, 큐 초기화에서 `deque((1))`로 썼다가 에러. `(1)`은 튜플이 아니라 그냥 정수라서, 요소 하나짜리 튜플은 `(1,)`처럼 쉼표가 필요함.
- 다음에 기억할 것: deque 초기화 시 원소가 단일 값이면 `deque([1])`처럼 리스트로 감싸고, 좌표처럼 여러 값을 묶을 땐 원소를 튜플로 `deque([(r, c)])`.
