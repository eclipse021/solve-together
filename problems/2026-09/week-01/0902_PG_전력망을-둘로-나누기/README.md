### 준희

- 접근: n이 최대 100이라 완전 탐색으로 충분하다고 판단. 전선을 하나씩 끊어보고(`wires[:i] + wires[i+1:]`), 남은 전선으로 1번 정점과 연결된 집합을 `set`으로 계속 확장(`update`). 한쪽 집합 크기가 나오면 `abs(n - len(s) * 2)`로 두 그룹 차이를 구해 최솟값 갱신.
- 막힌 지점: 처음엔 DFS로 연결 요소를 세야 하나 고민했는데, `set`으로 훨씬 쉽게 풀릴 것 같아 방향을 틀었음. (set을 쓰는 아이디어는 힌트를 좀 얻어서 금방 풀림)
- 다음에 기억할 것: n이 작으면 그래프 탐색을 정석대로 구현하지 않아도 됨 — 연결된 정점을 `set`에 계속 `update`하며 n번 반복하면 연결 요소가 다 채워진다. 두 그룹 크기 차이는 `abs(n - len(s) * 2)` 한 줄로.
