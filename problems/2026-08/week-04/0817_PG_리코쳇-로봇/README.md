## 짧은 회고

### 준현

- 접근: 모든 원소의 최소 거리 및 방문 여부를 visited로 표현해 BFS로 cnt가 작은 순으로 채워지고 중복을 제거하도록 구현
- 막힌 지점:
  - Java 문법에서 C++ 습관이 많이 남아 `arr[101][101]`, `Node(...)`, `q.empty()`, `q.push()`처럼 작성했고, 문자열 비교도 `==`를 사용했다.
  - 객체 지역변수 초기화와 `Queue` 생성 방식도 익숙하지 않아 컴파일 에러가 발생했다.
- 다음에 기억할 것:
  - 배열은 `int[][] arr = new int[n][m]`
  - 객체 생성은 `new Node(...)`
  - `Queue`는 `Queue<Node> q = new ArrayDeque<>()`, `offer` / `poll` / `peek` / `isEmpty`
  - `peek()` 후 `poll()`할 필요 없이 `Node cur = q.poll()`로 바로 꺼낼 수 있음
  - 클래스명은 `pair`보다 `Pair`처럼 대문자로 시작하는 습관 들이기
  - `cnt`를 `Node`에 따로 들고 다니지 않고 `visited[cur.r][cur.c] + 1`로 거리 계산하는 방식도 가능함
