### 준희

- 접근: 처음엔 딕셔너리 카운트 곱연산이나 `combinations`를 고려했으나, 매칭 선택이 독립적이지 않고 내부 1:1 매칭을 따로 구현해야 하는 번거로움에 부딪힘. → 제한(N ≤ 8)이 매우 작으므로 `permutations`로 완전 탐색. 뽑힌 유저 id와 banned_id를 같은 인덱스끼리만 1:1 비교(길이 같고, `*` 아니면 문자 일치)해 검사 로직을 단순화.
