## 짧은 회고

### 준현

- 접근: 점수 목록을 List<Integer>[][][][]에 나눠 저장하고 정렬한 뒤, 필요한 리스트를 골라 이분 탐색했다.
- 막힌 지점:
  1. Java의 다차원 List 배열 선언 방식이 익숙하지 않았고, 문자열 파싱 과정에서 split() 사용법을 공부했다.
  2. 재귀 이분 탐색에서 재귀 호출 앞에 return을 붙이지 않아 결과가 전달되지 않는 실수가 있었다.
- 다음에 기억할 것:
  1. 다차원 List 배열은 List<Integer>[][] arr = new ArrayList[x][y]처럼 선언하고 각 칸을 new ArrayList<>()로 초기화하자.
  2. 문자열은 String[] s = str.split(" ")처럼 나눌 수 있고 결과는 String[]으로 반환된다.
