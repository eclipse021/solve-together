## 짧은 회고

### 준현

- 접근: 1) 각 알파벳을 비트값으로 바꾸고, 2) DFS로 모든 조합을 구했다.
- 막힌 지점: 풀이 로직보다 Java 문법이 익숙하지 않아 Map 선언과 순회, char와 String 변환, List 정렬과 배열 변환 방법을 찾아봄,, DFS에 String을 넘길 때 깊은 vs 얕은 복사 인지 헷갈렸다.
- 다음에 기억할 것:
  1. Map은 인터페이스 타입으로 선언하고, 빈도수는 getOrDefault를 사용하면 간단하게 갱신할 수 있다. + contains가 아닌 containsKey, containsValue로 존재 유무 확인 가능
  2. String은 불변 객체라 DFS 인자로 넘길 때 배열처럼 clone을 고민하지 않아도 된다.
  3. Map 전체 순회는 um.entrySet() 사용하기
  4. 문자열 목록 정렬은 a.compareTo(b) 사용하기 -> 문자열 오름차순
  4. List를 배열로 바꿀 때는 toArray(new String[0])을 사용하고, int 배열은 생성 시 0으로 초기화된다.
    - 기억이 안 나면 int[] arr = new int[list.size()]; 이렇게 선언 후 복사하자

### 준희

- 접근: 코스 길이 `c`마다, 모든 주문을 `sorted` 후 `combinations(o, c)`로 조합을 뽑아 `"".join`해 리스트에 모으고 `Counter(...).most_common()`으로 빈도 집계. 최다 빈도가 2 이상이면 그 메뉴를 채택하고, 이후 동점(직전과 같은 빈도)인 메뉴도 함께 채택. 마지막에 정렬.
- 막힌 지점: `all_comb`를 자꾸 set(종류만 담는 것)으로 생각해서, "종류를 담아두고 다시 각 종류를 orders마다 세야 하나?" 하고 헤맴. → 그냥 조합을 리스트에 다 담고 `Counter`로 한 번에 세면 됐음. (조합 알고리즘 자체는 바로 떠올림)
- 다음에 기억할 것:
  - 빈도 집계 후 상위 뽑기는 `Counter(...).most_common()`.
  - 문자열 정렬은 `"".join(sorted(s))`.
  - "종류만 모으고 따로 세기"보다 "다 담고 한 번에 Counter"가 간결.
