## 짧은 회고

### 준현

- 접근: 메두사의 최단 경로는 BFS로 경로를 구했으며, 이후 메두사 시선 범위는 시뮬레이션으로 구현
- 막힌 지점:
  - 메두사의 최단 경로에 대해 맨 처음에는 백트래킹을 생각했으나 시간 복잡도 상 말이 안되고, 다익스트라 처럼 BFS를 그리디 방식으로 접근함
  - 상하좌우로 메두사가 시선을 보거나, 기사가 움직일 때 if-else 패턴이 아닌 하나의 반복문으로 일관된 방식을 사용하도록 설계함
- 다음에 기억할 것:
  - 각 지점의 최단 경로를 `vector<int> short_list[51][51]` 에 저장 했는데 각 지점에 직전 원소의 값을 넣는 것으로 더 빠른 시간으로 구현 가능
  - 2048 문제나, 왕실의 기사 문제 등을 통해 상하좌우에 대해 일관적으로 코드를 잡는 습관 기르자!

### 준희

- 접근: 이전(4/10)에 풀어둔 풀이를 올림. 메두사 경로는 공원에서 BFS로 거리를 구한 뒤, 집에서부터 거리가 1씩 줄어드는 칸을 상하좌우 순서로 따라가 최단 경로를 만듦. 매 턴 4방향 시야를 모두 계산해 돌이 되는 전사가 가장 많은 방향(동률이면 상하좌우 순)을 고르고, 돌이 안 된 전사는 시야 밖으로만 두 번(상하좌우 → 좌우상하) 메두사 쪽으로 이동.
- 막힌 지점: 최단 경로 추적과 시야/그림자 계산은 해설지를 참고함. 시야는 방향별 3갈래(좌대각·직진·우대각)로 BFS하며 밝히고, 전사를 만난 빛의 종류를 기록해 그 뒤쪽을 그림자로 지우는 방식으로 바꿈. 전사 이동과 메인 루프는 직접 작성.
- 다음에 기억할 것:
  1. 경로를 저장하지 않아도, 도착점 기준 BFS 거리만 있으면 출발점에서 거리가 1 줄어드는 칸을 우선순위대로 따라가 최단 경로를 복원할 수 있음.
  2. 부채꼴 시야는 수식 대신 3갈래 BFS로 밝히고, 가려진 빛의 종류별로 그림자를 퍼뜨려 지우면 됨.
