## 짧은 회고

### 준현

- 접근: 해당 지점까지의 결과가 다음 결과에 영향을 미친다고 판단해 dp로 문제 해결
- 막힌 지점: r,c 마다 최대 값이 다르므로 이중 배열 사용
- 다음에 기억할 것: dp로 어떻게 상태 저장할지 계속 집중하자!

### 준희

- 접근: 맨 아랫줄을 `dp` 초기값으로 두고 아래→위로 올라가며 `dp[j] = max(dp[j], dp[j+1]) + triangle[i][j]`. 두 자식 중 큰 값을 부모에 누적, 맨 위 `dp[0]`이 답. 1차원 배열 하나로 in-place 갱신.
- 막힌 지점: 오랜만의 DP라 감이 안 왔는데, 막상 상태정의(아래에서 올라오는 최대합)를 잡으니 별거 없었음.
- 다음에 기억할 것: 경로 DP는 아래에서 위로 올리면 1차원으로 충분. bottom-up이면 배열 경계 처리도 깔끔.
